MERGE VIDEOS (FFMPEG)  --  SETUP GUIDE
=======================================

REQUIREMENTS: Windows 10 or 11, internet during setup only. No admin needed.


STEP 1  --  EXTRACT THE ZIP
---------------------------
Right-click the ZIP file  ->  Extract All  ->  Extract

  Important: EXTRACT it. Do NOT double-click Install.bat while it's
  still inside the ZIP viewer, or Windows will run it in a temporary
  location and the install will fail.


STEP 2  --  (RECOMMENDED, OPTIONAL) ACCEPT THE PUBLISHER
--------------------------------------------------------
Only relevant if this ZIP shipped with a MergeVideos-Publisher.cer.
If it does, double-click:

    Trust-Publisher.ps1

You may see "Windows PowerShell has stopped working" or a security
prompt. Accept it. This is a one-time step per machine that lets
signed Merge Videos scripts run without prompting.


STEP 3  --  RUN THE INSTALLER
-----------------------------
Open the extracted folder and double-click:

    Install.bat

A dark window opens. It runs TWO stages in order:

  Stage 1: Pre-flight check
      Verifies Windows version, PowerShell, execution policy,
      internet, and FFmpeg availability. If anything is red,
      it stops and tells you EXACTLY what to fix.

  Stage 2: Install
      Unblocks the extracted files, installs FFmpeg if missing
      (winget first, else portable download from gyan.dev, about
      100 MB), copies the merge scripts to your user profile,
      and creates Desktop + Start Menu shortcuts.

Wait for  "Ready to use"  in green. Then press any key.

  First-run takes a few minutes because FFmpeg (about 100 MB)
  is being downloaded.

  If Windows shows "Windows protected your PC":
      Click "More info"  ->  "Run anyway"
      This is normal for scripts that are not signed by a
      big-name commercial CA. The install is safe -- source is
      https://github.com/advansnexus/merge-videos-ffmpeg


STEP 4  --  CONFIRM IT WORKED
------------------------------
You should now have on your Desktop:

    Merge Videos

And in your Start Menu (search for it):

    Merge Videos

Setup is done. You will not need to run the installer again.


HOW TO USE
----------

1. Double-click "Merge Videos" (Desktop or Start Menu).
   A dark window titled "Merge Videos (FFmpeg) - Advans" opens.

2. Left panel:
   * Click "Add Video..." to pick one or more videos. Repeat if
     needed. The list on the left shows them in play order.
   * Use "Move Up" / "Move Down" to reorder, or "Remove" to drop one.
   * Click "Choose output location..." and pick where to save the
     merged file.

3. Right panel:
   * Summary shows total duration, size, and whether audio will be
     injected for any silent inputs.
   * When you click "Start Merge", the progress bar and green log
     update in place.

4. When you see the green SUCCESS line, the merge is saved to the
   output location you picked. Play the file to confirm.


TROUBLESHOOTING
---------------
Install.bat opens then immediately closes
    ->  You double-clicked while still inside the ZIP. Extract
        the ZIP first (right-click -> Extract All).

Pre-flight says "AllSigned" execution policy
    ->  Your machine requires signed scripts. If this ZIP shipped
        a MergeVideos-Publisher.cer, run Trust-Publisher.ps1 first
        (Step 2 above). Otherwise ask IT to relax to RemoteSigned
        for your user.

Install stalls at "Downloading portable FFmpeg..."
    ->  Corporate proxy is blocking gyan.dev. Download this file
        manually in a browser:
          https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip
        Extract it into  %LOCALAPPDATA%\FFmpegTools\portable\
        Then re-run Install.bat.

"Merge Videos" shortcut opens a black window then disappears
    ->  WPF is missing or execution policy is blocking. Run
        Test-System.ps1 from the ZIP folder to see which one.

Merge fails with "Input link ... parameters do not match"
    ->  This should be handled automatically now. If it isn't,
        run Get-DiagnosticInfo.ps1 and send the ZIP to the
        maintainer.

Anything else
    ->  Double-click Get-DiagnosticInfo.ps1 in the extracted folder.
        It builds a ZIP of your system info + install logs + FFmpeg
        version. Email that ZIP to whoever shared this tool. It
        contains NO video content -- just diagnostic info.


UNINSTALL
---------
Double-click  Uninstall.bat  in the extracted folder.
Removes the shortcuts and scripts. Leaves FFmpeg installed (other
tools may use it).


OUTPUT FILE IS SAVED WHEREVER YOU CHOSE IN THE SAVE DIALOG.
